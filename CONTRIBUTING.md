# Contributing to IRS — Income Records System

Thanks for taking the time to help improve IRS.

IRS is currently maintained as a proprietary, single-author project. Bug reports, reproducible test cases, feature requests, screenshots, and diagnostic information are welcome.

## Bug Reports

Please use the repository's **Bug Report** issue form.

A useful bug report includes:

- the IRS version;
- the World of Warcraft Retail version;
- clear steps to reproduce the problem;
- what you expected to happen;
- what actually happened;
- any Lua error text;
- whether the problem still occurs with other addons disabled, when practical to test.

Please remove account names, character names, realm names, or other information you do not want to post publicly from logs or screenshots.

## Feature Requests

Please use the **Feature Request** issue form and describe the problem or workflow the feature would improve. Describing the goal is usually more useful than prescribing a particular implementation.

## Pull Requests and Code Contributions

Unsolicited code contributions and pull requests are **not currently accepted**.

If a code contribution would be useful, please open an issue first. A pull request may be reviewed only when the maintainer has explicitly requested or approved the contribution in advance.

This policy helps keep copyright ownership and future licensing decisions straightforward. If outside code contributions are accepted in the future, contribution terms will be established before that code is merged.
