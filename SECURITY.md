# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of IRS — Income Records System.

## Reporting a Security Issue

If you believe you have found a security-sensitive problem, please avoid posting exploit details, private account information, or sensitive SavedVariables data in a public issue.

Use GitHub's private vulnerability reporting option from the repository's **Security** tab when it is available.

If private vulnerability reporting is not available, open a minimal public issue titled **Security contact requested** without including sensitive technical details. The maintainer can then arrange an appropriate private channel.

For ordinary addon bugs that are not security-sensitive, use the standard Bug Report issue form instead.
